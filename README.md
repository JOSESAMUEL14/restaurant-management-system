## 📋 Project Overview

TASTYBITES is a premium, fully-functional Restaurant Management System with a stunning 7-star luxury interface. It combines a console-based Java backend with a beautiful web frontend, offering a complete dining experience from menu browsing to order tracking.

---

## ✨ Features

### 🍽️ Customer Features
- **Premium Menu Display** - 60+ dishes with real food images
- **Category Filters** - Browse by Starters, Main Course, South Indian, Desserts, Beverages
- **Dietary Preferences** - Veg/Non-Veg/Both filter
- **Shopping Cart** - Add items, update quantities, remove items
- **Smart Discounts** - Combo offers (10-20% off) & value discounts
- **Table Booking** - Interactive floor map with 8 tables
- **Payment Options** - Cash, Pay Online (QR Code), Others
- **Live Order Tracking** - Real-time status updates with animations
- **Tax Invoice** - Printable receipts with all details
- **Loyalty Points** - Earn points on every order

### 👨‍💼 Admin Features
- **Live Queue Analysis** - Real-time order monitoring
- **Order Management** - View and update order status
- **Menu Manager** - Add/Delete food items
- **Table Status** - Book/Release tables
- **Sales Analytics** - Total sales, average order value
- **Dietary Distribution** - Veg/Non-Veg item counts

### 🎨 Design Highlights
- **Golden Luxury Theme** - Deep charcoal + Royal Gold
- **Glassmorphism Effects** - Modern frosted glass design
- **Smooth Animations** - Scroll reveals, pop-ups, transitions
- **Floating Vegetables** - Animated background in order tracking
- **Responsive Design** - Works on Desktop, Tablet, and Mobile
